## 先分清三类信息

| 信息 | 能说明什么 | 不能说明什么 |
| --- | --- | --- |
| Programme aims 与课程结构 | 项目希望培养的能力、课程所属方向和毕业学分要求 | 不能保证某门课一定在某学期开设，也不等于就业承诺 |
| CityUHK 职业与实践服务 | 学校当前提供的求职平台、咨询、企业项目和课程入口 | 不保证获得实习、面试或录用 |
| 历届学生经验 | 课程感受、求职准备方法和常见问题 | 不代表本学年规则、所有教师或当前招聘市场 |

## 官方可以确认的两个培养方向

### MIS · 管理智能系统

2026 入学项目说明将 MIS 定位为主要面向非 IT 背景申请者，重点包括评估前沿 IT、协调 IT 支持的商业项目，以及管理商业信息系统的运行。项目强调商业知识与 IT 支持的问题解决能力。

### FIT · 金融与智能科技

2026 入学项目说明将 FIT 定位为面向具有一定 IT／IS 或金融／会计基础的申请者，重点是把智能科技与业务领域知识结合；金融科技是其中最具代表性的应用，但不是唯一应用。

::: warning 培养方向不是职位保证
官方项目说明没有承诺毕业生一定进入某个岗位、公司或薪酬区间。本站不会把修读一两门 AI、数据或金融课程直接写成“可胜任 AI 工程师”“保证进入金融业”等结论。
:::

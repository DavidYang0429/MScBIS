## CityUHK 官方学习资源

### LibraryFind 与专业数据库

- [Run Run Shaw Library](https://www.cityu.edu.hk/lib/)：进入 LibraryFind、Databases、Research Guides、Course Reserves 与馆际互借。
- [Library Databases](https://www.cityu.edu.hk/lib/collect/db/)：按数据库名称或学科查找学校订阅资源。
- [Research Guides](https://libguides.library.cityu.edu.hk/)：按学科查找检索方法、数据库和引用资源。
- [Financial Data Guide](https://libguides.library.cityu.edu.hk/ac/acc/fd)：列出 OSIRIS、Factiva、Business Source Complete 等公司与金融数据入口。

::: tip 为什么还要查看 Databases
CityUHK Library 的说明指出，部分法律、公司和金融专业数据库内容不会完整出现在 LibraryFind 的统一检索结果中。需要公司资料、财务数据或市场信息时，应同时检查 Databases 与相应 Research Guide；访问权限以你的 EID、数据库许可和当前订阅为准。
:::

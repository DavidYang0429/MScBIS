::: info 内容状态

## 先看结论

城大 enrolment 不是到校“报到”一次就结束。正确顺序是：启用 EID 和验证方式 → 完成全部线上预注册 → 等待身份文件核验 → 按 confirmation letter 完成线下注册与资格检查 → 确认学生证及注册后状态。

## 注册流程

### 1. 启用 EID 与验证方式

- 从 CityUHK 官方入口启用 EID，不使用群聊转发的登录页。
- 设置多重验证和恢复方式，确认学校邮箱与 AIMS 均可登录。
- 更换手机前先迁移验证方式；已经无法验证时，通过学校 IT 支援处理。

### 2. 完成全部线上预注册

学校当前列出的在线步骤包括：

1. 启用 EID；
2. 阅读并接受 enrolment declaration；
3. 更新联络资料；
4. 选择个人资料直销用途；
5. 非本地生完成保险声明；
6. 上传学生证照片；
7. 提交身份文件核验；
8. 完成健康问卷。

页面显示“已提交”不一定表示所有材料已经通过。遇到照片或身份文件退件，要根据原因重新上传并保留时间记录。

### 3. 准备线下资格核验

- 按个人通知准备旅行证件、学历、学位、正式成绩资料和 Offer 条件要求的原件。
- 非本地生准备电子签证、入境所用证件和已激活学生身份的入境记录。
- 不同文件中的姓名或证件号码不一致时，提前向学校确认解释与补证方式。
- 线下注册不能授权他人代办。

### 4. 完成 enrolment 与学生证手续

- 提前保存预约确认并规划到校路线，现场留出排队和补充核验的时间。
- 需要补件时，记录准确文件名称、提交渠道、负责部门和新期限。
- 核对学生证英文姓名、照片和学生号码；发现错误立即按学校流程更正。

### 5. 注册后总检查

- 在 AIMS 核对 programme information、个人资料、学费状态和 Personal Class Schedule。
- 查看学校邮箱中的课程、迎新、保险和非本地生手续通知。
- 按资格继续办理香港身份证、电话卡、银行和学生交通优惠等事项。
- 需要更新香港地址或香港身份证资料时，只通过学校指定渠道提交。

## 常见问题

- **预注册完成但没有 appointment：** 检查身份文件、Offer 条件和签证状态是否仍待处理。
- **航班或恶劣天气影响注册：** 保存证明并尽快书面联系负责部门，以学校最新安排为准。
- **收不到邮件：** 检查垃圾邮件、邮箱容量与转发规则，再从 AIMS 核对登记邮箱。
- **AIMS 与邮件状态不一致：** 同时保存截图和时间，以 AIMS 当前状态及学校书面回复为判断依据。

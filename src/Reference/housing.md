# 宿舍、租房与盖印

::: info 内容状态
**最后更新：** 2026-07-26<br>
**适用范围：** 2026/27 CityUHK 全日制硕士新生，以及准备在香港私人市场租房的学生<br>

## 先分清三套机制

| 方案 | 2026/27 申请与分配 | 关键条件 |
| --- | --- | --- |
| 九龙塘 Hall 7 | 主轮已于 2026-05-27 截止；合资格申请超额时抽签 | 获配并确认后再填写 roommate／flatmate preference，不是申请前必须组队 |
| 马鞍山宿舍 | 主轮已于 2026-05-27 截止；超额时抽签 | 全日制硕士、双人房，新生优先 |
| 九龙塘／南山苑 Shared Units | 2026-07-28 12:00 至 2026-08-03 17:00；先到先得 | 必须预先组成完整同性别合资格小组，并在通知后的短窗口内完成付款 |

主轮“抽签”、获配后的“偏好匹配”和 Shared Units 的“预组队先到先得”不是同一件事。宿舍供应非常有限，任何申请都不是床位保证。

## 2026/27 已公布信息

### 九龙塘 Hall 7

- 住宿期：2026-08-24 09:00 至 2027-05-24 12:00。
- 每学期每人约 HK$22,800–35,750，按房型不同。
- 费用包括网络、水电，不包括膳食、洗衣和空调。
- 2026-06-16 公布结果；确认期为 06-16 至 06-22；偏好填写期为 06-16 至 06-30。

### 马鞍山宿舍

- 住宿期同为 2026-08-24 至 2027-05-24。
- 双人房；2026/27 每学期每人 UGC-funded 约 HK$15,550，non-UGC／self-financed 约 HK$19,450。
- 2026-06-16 公布结果，确认期为 06-16 至 06-23。

### Shared Units

- 九龙塘为 2 或 3 人同性别完整小组；南山苑为 7 或 8 人同性别完整小组。
- 住宿及合约期为 2026-08-24 至 2027-07-23，共 11 个月。
- 九龙塘每人约 HK$78,000；南山苑按房型约 HK$48,000–78,000，金额包含 11 个月住宿费和 1 个月可退按金。
- 结果自 2026-07-29 起分批发出；付款详情发出后须在 24 小时内处理。
- 申请当天仍要重查成员资格、房型、金额、退款条款和 AIMS 入口。

## 没有宿舍时怎么找房

1. 先计算真实月成本：租金、押金、佣金、印花税、水电网、管理费、家具、搬家和通勤。
2. 核验物业地址、实际房间、业主或代理身份、出租权和收款账户之间的关系。
3. 尽量实地看房；必须远程时，要求实时视频、完整合同、可核验收款主体并控制首笔付款风险。
4. 把租期、押金、提前解约、维修、费用、转租和退还押金条件写入合同。
5. 入住当天记录水电表、钥匙、家具和房屋状态，由双方确认交收清单。

::: warning 付款顺序不能倒置
未核验房源、出租权、合同和收款主体前，不因“马上有人抢”而支付大额定金。CityUHK 的校外住宿页面只提供参考，私人合同仍由学生自行审慎判断。
:::

## 租约盖印

- 香港住宅租赁协议一般须在签立日期后 **30 天内**盖印，起算点不是入住日。
- 房东、租客、地产代理或代表均可办理，费用分担由各方约定；最好直接写进租约。
- 每位签约人都应保存最终签署版、印花证明、付款凭证、收据和交收记录。
- 印花证明表示相关印花税已经处理，并不认证房源、业权或合同内容一定真实。

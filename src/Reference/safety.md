# 付款与信息安全

::: info 内容状态
**最后更新：** 2026-07-26<br>
**适用范围：** 赴港前及在港期间处理学费、签证、租房、银行、通信、兼职和网络交易的学生<br>
**本次更新：** 把知识库中的反诈骗资料改为“行为信号 + 二次核验 + 事后止损”框架，并加入 2026 年学生相关风险提醒。
:::

## 先记住一个判断

对方一旦同时制造恐慌、要求保密、催促立即付款、索取验证码或要求共享屏幕，就先停止操作，再通过你自己找到的官方入口重新核验。来电显示、头像、姓名、学校资料甚至制服画面都不能独立证明身份。

## 学生最常遇到的场景

| 场景 | 高风险信号 | 正确核验方式 |
| --- | --- | --- |
| 学校缴费 | 要求改付私人账户、二维码域名不符、声称马上取消 Offer | 回到 Offer、Admission Application System、AIMS 或学校财务页面 |
| 学生签证 | 声称付费加急、要求发送完整证件或验证码 | 从 CityUHK 或入境处官网重新进入办理入口 |
| 租房定金 | 不允许核验房源与出租权、收款人不断改变 | 核对物业、业主／持牌代理、租约和收款主体 |
| 冒充机构 | 要求“安全账户”、视频审讯、不得告诉家人学校 | 挂断后自行查找机构公开联络渠道 |
| 银行与客服 | 要求屏幕共享、远程控制、一次性验证码 | 立即结束通话并使用银行官方应用或官网 |
| 兼职与投资 | 先垫资刷单、保证收益、借用账户“走流水” | 不转账、不借账户，保存证据并通过官方渠道求助 |

## 付款前五步

1. 找到产生这笔费用的原始文件：Offer、学校系统、正式租约或商户订单。
2. 核对完整域名、收款人名称、金额、币种和用途。
3. 不使用对方在聊天中提供的回拨号码；自行从官网进入。
4. 大额付款让一位可信的人独立复核，并设置冷静时间。
5. 保存正式页面、合同、付款凭证和收据，但遮盖公开分享中的敏感信息。

## 账号与资料边界

- 不向任何人提供密码、一次性验证码、多重验证恢复码或远程控制权限。
- 证件副本只交给可以解释用途和保存方式的正式机构；能遮盖的无关字段先遮盖。
- 不替陌生人开户、收款、换汇、购买或实名电话卡。
- 学校邮箱、AIMS 和银行启用独立强密码、双重验证和登录／交易通知。
- 发现新设备、收款人或自动转账授权时立即核对。

## 已经发生怎么办

- **已经转账：** 立即联系汇出银行说明涉嫌诈骗，尝试止付或追款，并保存交易编号和完整沟通证据。
- **已经共享屏幕或安装远控：** 断开网络，从可信设备修改银行、邮箱和学校账户凭证。
- **已经交出验证码：** 锁定相关卡片与账户，检查新增收款人、FPS、电子钱包和直接扣账授权。
- **已经发送证件：** 停止继续发送，保存证据并通知相关机构提高账户监控。
- **涉及人身威胁或持续损失：** 使用香港警方及相关机构在官方网站公布的紧急或报案渠道，不继续支付所谓保证金或解冻费。

::: tip “没有查到风险”不等于安全
警方的防骗工具可以作为一层筛查，但新账户、新号码和新网址可能尚未被报告。最终仍要核对交易目的、身份、合同和官方渠道。
:::

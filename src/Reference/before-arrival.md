# 行前与学生签证

::: info 内容状态
**最后更新：** 2026-07-26<br>
**适用范围：** 已获 CityUHK BIS Offer、需要学生签证／进入许可的 2026/27 非本地新生<br>
**本次更新：** 融合学生签证起步、城大担保流程、ID 995A、电子签证和行前清单；重新核验处理时间、申请渠道及费用边界。
:::

## 先看结论

拿到 Offer、城大收到材料和入境处批准签证是三个不同状态。城大可以为合资格课程学生担任本地担保人，但最终决定由香港入境事务处作出。城大建议整段流程预留 **8 周或更长**；入境处公布的通常处理时间是收到全部所需文件后的 **约 6 周**，两者起点不同，都不是获批承诺。

## 完成路径

### 1. 先确认个人 Offer

- 阅读完整 Offer package，确认课程、入学学期、英文姓名、接受期限和条件。
- 只通过本人 Admission Application System 或 Offer 指定渠道接受和付款。
- Conditional Offer 的条件核验与学生签证可以并行，但提交签证不会自动延长条件期限。

### 2. 请求城大签证担保

- 登录 Admission Application System，进入适用于 Taught Postgraduate Programme 的 Visa／Entry Permit Sponsorship。
- 使用当前版本的 ID 995A，按真实个人情况填写；不要照抄往届样例。
- 准备旅行证件、录取文件、照片、财力证明及城大当期清单要求的其他材料。
- 城大目前列出的签证申请行政费为 **HK$600**，不包含获批后向入境处缴付的签证费用；付款前仍要以本人系统为准。
- 保存提交确认、付款凭证、材料副本和需要邮寄时的物流记录。

### 3. 跟进校内审核与入境处审批

- 城大先检查材料并处理担保人文件，再把合资格申请递交入境处。
- 每天查看申请账户、登记邮箱和垃圾邮件，补件时记录提交日期与文件版本。
- 状态长时间不动时，先确认当前是在学校审查、等待纸质材料，还是已经送交入境处。
- 不要另建第二份相同申请，也不要把证件、银行资料或验证码发给群聊里的“加急联系人”。

### 4. 获批后核对出行文件

- 通过官方路径缴费并下载电子签证，核对姓名、旅行证件号码、学校、签证类别和有效期。
- 内地居民还要按所在地要求办理往来港澳通行证及相应赴港签注；电子签证不等于全部出境文件已经齐备。
- 把电子签证、Offer、住宿地址和学校联络方式同时保存到手机本地、可信云端和纸质备份。
- 入境时保存 landing slip；它记录抵港日期、逗留条件和期限，注册及后续手续可能需要。

## ID 995A 提交前检查

| 检查组 | 必须一致的内容 |
| --- | --- |
| 身份 | 英文姓名、出生日期、证件号码、国籍或地区 |
| 课程 | 学校、课程全名、修读模式、入学和预计就读日期 |
| 经济 | 资金来源、金额、资助人关系与证明文件 |
| 文件 | 当前版本、完整页数、照片、签名、日期和附件 |

::: warning 不要使用“万能模板”
表格版本、页数和提交方式可能调整。每次递交前都从入境处页面重新下载，并同时阅读城大当期 checklist。
:::

## 出发前的最小清单

- **入境文件包：** 旅行证件、电子签证、适用签注、Offer、住宿地址和紧急联系人。
- **注册文件包：** 个人 Enrolment Notification 要求的学历、成绩、身份和签证材料。
- **首三日生活包：** 支付工具、充电设备、转换插头、基础洗漱和少量换洗衣物。
- **离线备份：** 开启飞行模式后，仍能打开签证、地址、交通路线和重要联络资料。
- **行李核对：** 按航空公司当期规定检查重量、尺寸、药品、电池及其他受限制物品。

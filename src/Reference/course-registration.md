## 2026/27 当前节点

2026-07-28 起，新生可在 AIMS 查看 Personal Class Schedule。部分课程会由项目预注册；能看到课表不代表所有课程都可以自行删除，也不代表你已经完成整个学期的选课决策。

## 操作顺序

### 1. 先核对培养要求和预注册课表

- 对照 BIS programme requirement 区分必修、方向课程、共享选修和毕业学分。
- 在 AIMS 查看已经预注册的课程；核心课程通常由学校与学术单位安排。
- 预注册课程与个人计划冲突时，先向项目办公室取得书面说明，不要自行删除。

### 2. 查看个人 time ticket

- Registration time ticket 决定你从什么时候开始使用 AIMS Web Add/Drop。
- 不同 programme、cohort、修读模式和学位类别可能得到不同时间。
- 开放前测试 EID、多重验证和 AIMS 登录，不把账号交给他人代抢。

### 3. 核对课程与 section

- 在 Master Class Schedule 查看 CRN、section、学分、时间、名额、先修要求和 `WEB` 状态。
- Lecture、tutorial、laboratory 等相连班别可能需要同时注册。
- 同一课程代码的不同 section 可能有不同教师、时间与考核安排，不能只看课程名称。

### 4. 分清 Web 与 Non-Web

- `WEB = Y` 的课程在个人 time ticket 开放后使用 Web Add/Drop。
- 非 Web-enabled 课程、预注册课程调整及部分 restriction waiver，通过 AIMS 的电子申请流程处理。
- “申请已提交”不等于获批；最终必须回到 Course Registration Records 或 Personal Class Schedule 核验。

### 5. 以最终课表验收

- 每次 Add/Drop 后重新打开 Personal Class Schedule，核对课程代码、section、时间和地点。
- 阅读系统返回的每条错误；页面刷新或成功收件邮件都不能替代最终注册记录。
- Add/Drop 结束前，把最终课表再与 BIS 毕业要求核对一次。

## 常见系统提示

- **PREREQUISITE／TEST SCORE：** 核对先修记录，确有等效背景时按项目流程申请。
- **TIME CONFLICT：** 检查所有 lecture、tutorial 和考试安排。
- **MAXIMUM HOURS EXCEEDED：** 重新计算学分；超额修读需要正式批准。
- **PROGRAM／LEVEL RESTRICTION：** 联系开课单位，反复点击不会解除限制。
- **LINK ERROR：** 找到同一 section group 要求的配套班别并一起注册。
- **CLOSED SECTION：** 查看候补或认可替代课，不购买或交易名额。

::: warning 不要高频自动抢课
城大明确禁止尝试通过不公平方式取得课程名额，并会监测 Add/Drop 期间的系统活动。脚本刷新、账号共享和名额交易同时带来纪律与信息安全风险。
:::

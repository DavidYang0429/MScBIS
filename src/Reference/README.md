## 信息怎么分层

| 层级 | 用途 | 采用原则 |
| --- | --- | --- |
| 官方事实 | 日期、费用、资格、材料、办理入口 | 以 CityUHK、香港特区政府及监管机构当前页面为准 |
| 学生经验 | 实际耗时、常见困惑、生活选择、踩坑 | 只作为补充，不把个人经历写成统一规则 |
| 编辑结论 | 把不同来源整理成可执行步骤 | 明确适用范围、完成标准、异常处理和复核日期 |
| 历史内容 | 往届页面、截图、课程评价 | 保留贡献届别，不用于替代 2026/27 当前通知 |

## 2026/27 关键时间

| 事项 | 当前公开时间 | 你需要做什么 |
| --- | --- | --- |
| 城大硕士线下注册 | 2026-08-13 至 2026-08-29 | 先完成全部线上预注册，并以个人 confirmation letter 的预约为准 |
| AIMS 查看个人课表 | 2026-07-28 起 | 核对预注册课程、BIS 培养要求和个人 registration time ticket |
| 2026/27 Semester A 开课 | 2026-08-31 | 在 Add/Drop 结束前复查最终课表 |
| 硕士 Shared Units 申请 | 2026-07-28 12:00 至 2026-08-03 17:00 | 只适用于完整合资格小组，先到先得，付款窗口很短 |

::: warning 时间会变化
表格只记录 2026-07-26 可核验到的 2026/27 信息。个人预约、项目安排、系统状态和学校后续邮件优先级更高；2027/28 及以后不能直接沿用。
:::

## 来源与编辑边界

本板块的初始资料来自同一维护者的“留学工具”项目 `knowledge-base` 目录。这里只迁入与 CityUHK BIS 学生直接相关的内容，并重新组织为本站页面；港大、港中文、科大和理工的校级流程没有复制进来。

外部事实主要回到以下官方入口复核：

- [CityUHK 新生注册](https://www.cityu.edu.hk/sgs/student/masters/info-new-students/enrolment)
- [CityUHK 学生签证／进入许可](https://www.cityu.edu.hk/admo/non-local-students/visa/student-visa)
- [CityUHK 硕士选课](https://www.cityu.edu.hk/sgs/student/masters/coursereg)
- [CityUHK 硕士住宿](https://www.cityu.edu.hk/sro/StudentHousing/PGHalls/MDS/index.htm)
- [香港入境事务处：学生签证](https://www.immd.gov.hk/eng/services/visas/study.html)
- [香港入境事务处：香港身份证](https://www.immd.gov.hk/eng/services/hkid/reg_replace.html)

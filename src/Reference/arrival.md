# HKID、通信与银行

::: info 内容状态
**最后更新：** 2026-07-26<br>
**适用范围：** 初次以学生身份抵港、需要安排本地身份与基础生活服务的非本地生<br>
**本次更新：** 融合香港身份证、电话卡实名和银行开户资料；删去容易过时的套餐、优惠和单一银行推荐。
:::

## 建议顺序

1. 先确认学生签证已经入境激活，并保存 landing slip。
2. 按本人获准逗留期判断是否需要登记香港身份证，并尽早预约。
3. 先解决可以稳定接收短信的本地号码，再更新学校和重要账户联络方式。
4. 根据收生活费、FPS、交房租、外币消费和跨境汇款等实际用途选择银行。

## 香港身份证

新抵港、年满 11 岁并获准在港逗留超过 180 天的人，一般须在抵港后 30 天内登记香港身份证；获准逗留不超过 180 天或属于豁免类别的人不适用同一要求。

办理前应：

- 从入境处页面确认本人资格、所需原件和当前预约方式；
- 用实际旅行证件号码预约，并保存预约确认；
- 携带获批签证、入境记录及官方列出的身份文件原件；
- 领取时核对英文姓名、出生日期和证件资料。

## 电话卡与本地号码

香港本地 SIM 服务计划和储值卡在启用前都需要实名登记：

- 使用本人原始身份证明文件办理，不购买声称已经实名的电话卡。
- 已持香港身份证者应按当前规则使用香港身份证；尚未持有者可按运营商和监管规则使用有效旅行证件。
- 比较合约期、网络覆盖、限速、漫游、号码保留和解约成本，不只看首月价格。
- 完成后测试短信、通话和数据，再把学校、银行及双重验证逐项迁移到稳定号码。
- 不替陌生人实名电话卡，也不把本人号码、验证码或恢复码交给“代办”。

## 银行开户

香港银行没有一份适用于所有机构和所有账户的统一开户清单。银行会根据客户尽职审查要求了解身份、地址、税务居民地、开户目的和资金来源；材料齐全也不代表一定获批。

办理前建议比较：

| 维度 | 需要确认的内容 |
| --- | --- |
| 资格与材料 | 本人证件、是否须身处香港、地址和学生身份资料 |
| 日常使用 | FPS、ATM、扣账卡、现金存取和电子钱包 |
| 跨境需求 | 币种、汇款路径、汇率加价、手续费和限额 |
| 持有成本 | 月费、最低结余、海外提款、外币消费和离港后维护 |
| 安全 | 双重验证、即时通知、转账限额和报失渠道 |

开户后先用小额交易验证 FPS、提款或收款功能，再进行大额转账。不要为了“容易通过”虚构地址、资金来源或账户用途。

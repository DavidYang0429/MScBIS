——如来了吗？如来嘛！ FIT

老师：Chiamin Fung. 老师讲课的重点不是很明确，就PPT里的什么内容都讲一点，我能有限抓不住重点。但老师人不错的，挺热心。

课程内容：大概有十二章，每一张60-80ps，老师说这还是删减过的内容。课程中的文本信息很多，很多都是专业概念解释。个人觉得对于管理人才可能是个不错的课程，但没有涉及很多硬技能。又让我们学习过一个软件mpp，用来显示在同一个project中各方人员的schedule的。

期末考试：开卷，用自己的电脑机考（可以自己选择纸考），用了一个软件强制所有考生关网。

点名：每节课都点名。

给分：包括我在内的三个uu都不高，都是b class的，还有另个朋友说他的分也不高。

平时作业：每学三章，当堂机考quiz一次，影响final score。（大家可以悄咪咪google，但有些答案也找不到）

个人推荐指数：三颗星

——Zoie FIT

这节课主要围绕项目管理的知识，第一学期老师上课内容不是很清楚，有些知识点并不能理解。期末考试建议把小组论文一并打印当作材料。

——六元 FIT

这门课是Charming上的，上课现场会点名签到，一个学期几次，这门课程是理论课，课程内容比较多，平时有课堂作业（且需要现场密码登陆才能做，所以算是考勤比较严格的一门课），课堂canvas上课堂讨论算平时分，课堂之后会留点时间完成，不算难，提交完成即可，小组项目是选一个企业或者虚拟的也可以，做一个项目管理报告，期中不需要汇报，期末全员小组汇报（且需要在ppt对应汇报页面上写个人的名字），这部分需要多结合课程的内容完成，老师比较注重报告的一些细节。这门课考试开卷，题目比较综合，不仅限单以知识点，需要理解整门课的内容，老师给分可以，总体来说不算难。

——Cynthia FIT

这门课在我们这一年有两种体验，因为AB学期的负责老师不同，我是在A学期选的这门课，因此我的心得主要是基于Chia Min （Charming）老师的教学体验

课程内容设置上是以An Introduction to Project Management（ Kathy Schwalbe著）这本书作为基础，融合项目管理PMP认证考试的权威 - Project Management Body of Knowledge (项目管理知识体系指南，缩称PMBOK)进行安排。因此IS5540对于后续有志报考PMP的同学将有所帮助（PMP考试对于工作时间和专业培训时间有所要求，IS5540将满足对于专业培训时间的限制，但是课程内容并不是针对PMP考试内容的专门课，若想通过考试仍需一定功夫）。有利就有弊，因为结合了两本书的内容，导致IS5540每节课的知识量都非常巨大（Mrs. Charming自己也承认上这门课会提高语速，因为内容确实过多了），对于一部分同学来说会有念经的体验感。

课程节奏整体上非常紧俏，Mrs.Charming根据PMBOK将课程内容分为十大板块，每周讲授一个板块，每隔3~4周便会安排一个记分Quiz，用以检验先前的学习质量（算是Mrs.Charming的Quality Assurance）

Group Project算是这门课的重头戏，因为这个Group Project要求你和其他5个小组成员写一份完整的项目管理计划（现学现卖），同时占比只比期末考试少10%，所以Group Project的质量非常影响Final Grade，Final Week的时候有小组进行了十二小时马拉松式完成Project（指一个组预约掉一整天的学习室，只为凑在一起完成Group Project），从质量和保证成员身心健康的角度考虑，建议把Group Project的节奏和课程同步起来，这样Final Week只需要完成检查工作，同时也有更多的时间完成合理性验证。

最后谈谈期末考试，这门课的期末考试绝对不是只带着PPT去就能了事的，必须对内容有深刻的理解（这一点适用于CityU所有开卷课程的考试），因此应当花时间认真回顾每一板块学到了什么，某一管理流程有什么文件/会议，项目中遇到的各种问题有那些解决方案，构建好自己的知识体系才能写的出卷子且成绩稳妥！

——AvalonC FIT

Liv-999 发表于 2025年1月4日 查看原评论

2024 semA

课堂方面：

  • 签到算是最严格的了，必须在教室电脑上登录canvas签到，而且还会当场给签到口令。一般都是上完两小时后签到。签到时会有一道小题，主要就是这次课讲过的东西，不会计分可以随便选。
  • 没有课后作业，会在课堂最后留时间来做作业。只要提交了就会给分，不看质量，但建议好好写。
  • 课上会有提问环节但不会点人。在每次课后会有Google form来提交你回答问题的情况，我的建议是能写就写，即使不是你回答的也可以写（比如全班一起回答的问题）。
  • 非常建议在课前预习一下要学的东西，可以用谷歌翻译一下文档，快速过一遍都好，因为平均每次课60+满满的ppt，内容真的很多，有时一走神五六页ppt就过了。
  • 每次ppt的最前面一页会写要学什么东西，如果第一页能全看懂那就可以了。
  • 有三次quiz，全是单选题。可以带一页A4纸双面手写，总共3+3+4分，一道题0.5分。题目比较抽象，挺难在ppt中找到原答案的，所以建议自己多理解，尤其是预测过程和敏捷过程的区别。
  • 会有一个专门用来交流的平台，在里面的可以问和答问题，老师也会参与其中，和Google form一起计算平时分。

关于小组作业：

  • 最后要交一个系统的管理报告，这一届是可以使用GPT来生成系统的基本内容，可以每个人生成几个对比一下，最好是比较容易理解，有商业价值的项目，方便后面进行WBS的制作。
  • 主要的工作内容分为两个部分，一个是作为顾问角度，分析怎么来管理这个项目，这一部分需要是可预测过程，也就是从项目背景，项目章程开始一系列的报告。很多报告会有模板参考，但依然很难写。第二个部分就是作为学生角度，你们是怎么完成这份小组报告的，这一部分是需要敏捷过程的。主要会使用jira这个管理系统，就是一个在线的项目管理平台，需要给每个人分配任务，比如某个文件由谁完成之类的。jira是不能临时修改的，所以建议及时更新jira中任务的状态，不然最后的结果会很难看。
  • 最后要提交的是一份完整的报告，包括顾问角度和学生角度。老师会给要写的所有文件列表，一定要认真检查有没有漏掉东西，也可以在学期后期约老师讨论一下项目看是不是完整。
  • 多多请教GPT老师但不要照抄，最后会查AI率，可以自己找淘宝查，建议不要超过30。超过了可能会被发邮件要求解释。
  • 如果可以建议自己当组长，虽然会很痛苦但可以更好理解项目管理的难点，比如风险管理，人员管理等。建议每周上完课就直接完成本周对应报告，时间一长容易忘了该写什么。我认为这个小组作业是最需要交流的一个作业，如果可以建议找熟悉的朋友或者能线下见面的同学会简单一些。
  • 老师是可以随时查看jira的进度的，而且会有一次中期检查，所以不要搞突击。

关于演讲：

  • 17分钟的演讲，会有计时器，到点就会提醒，结束老师会进行提问，注意不要超时，可能会影响分数。

关于考试：

  • 这一届是第一次闭卷，可以携带一张A4纸，双面手写，不允许打印。根据老师说的降低了难度，没有要写报告的部分，只需要理解最基本的概念就可以。不会考默写。
  • 最后一次上课会讲解一下考试重点，最后考试内容确实就在重点范围内，建议去听一下。
  • 期末考试9道题，时间有点紧张，建议写快一点：下面是简单的回忆版：
    1. 给出了一些质量管理工具，哪个工具适合哪种情况。主要作用于质量管理计划的哪个过程？
    2. 给出6个情景，选出最适合的沟通方式。（formal/ informal written/ verbal）
    3. 在一个可预测的项目里，你被要求在项目中加入一个新的部分并且预计关键路径需要增加两周，你该怎么做？你需要通知谁？你该什么时候去通知他们？
    4. 在敏捷过程项目里，你是一个team member，你被通知要加入2个stories，你该怎么做？
    5. 你被要求开发一个餐馆的移动应用，目前最重要的限制是时间，但餐馆老板认为花费和质量也很重要，你该选择怎么样的开发方式？为什么？
    6. 在预测过程中，你刚计划并决定了一个16周的项目计划，但客户要求你缩短到14周，你该怎么做？
    7. 在敏捷过程中，如果你想要很好的控制和监管项目的进程，你该举行什么会议？
    8. Critical Path Analysis，画网络图，计算关键路径，free float和total float。
    9. 计算EVM。

Chia Min确实是一个很负责的老师，但讲课的时候很难抓到她认为的重点，上课确实很容易走神。不过有问题可以下课问她或者发邮件，回复都非常及时。

项目管理入门课程，对于想当项目经理的朋友而言应该非常有用。两个教授冯洪嘉敏和RUPA通常一位在semA开课，一位在semB开课。身边选嘉敏section的同学没有一个不喊折磨的，因此如果希望上课体验轻松一些，强烈建议选择RUPA的section。我是把semA预注入的嘉敏section直接退了，等到semB再上的RUPA的section。
以下视角均基于RUPA的section。

课堂：

  1. 课间休息时会有个扫码答题，算是签到，不过随便乱答都行，经常看到有人就输个“1”交上去笑死。
  2. 课程内容是IT项目管理的各个文书模块，似乎是十个左右，记不太清，本人这门课学的尤其不专注hh
  3. 通常前2小时是讲课，后1小时做项目文书，但RUPA让大家写个10分钟左右后就会直接给答案，直接跟着教授打字就行了，后面我们都戏称这是“金山打字”课......
  4. 需要使用到的软件是 Microsoft Project，但因为都是在机房上课，直接在机房电脑用软件就行。RUPA这边不涉及Jira，但嘉敏那边会讲Jira。
  5. 学期中后段会有两次quiz，6道选择题，算入总分，在机房电脑做，严格禁止作弊或交流。不过都是从题库里面出的题，可以找找学长学姐们要一下题库，考前速看几遍记一下答案。

作业：

  1. 唯一的平时作业就是上面说的课堂最后1小时要做的那个东西。因为老师会直接给答案，所以很建议当堂做完就当堂交了，以免夜长梦多。
  2. 特别要注意的是，RUPA对canvas的操作手法十分诡异，她从不设置提交截止日期是哪一天，只设置available日期是从哪天到哪天，这会导致canvas日历上不会提醒这门课的作业的截止日，非常恐怖，所以千万要细心点确认一下自己每周要交的东西是不是交了（因此非常建议平时作业当堂做当堂交）。
  3. 小组作业（6人组）是出一份项目管理的报告书，自己定公司和主题即可，交付的必须是IT项目，然后整个过程都是架空进行，你想随便给什么微软苹果迪士尼蜜雪冰城立项都行，不需要像5411那样要真的去联系现实中的公司。
  4. RUPA会给出最终报告的结构模板，你只需要依样画葫芦，填鸭式完成，所以并不会很费心思。这也是很推荐选RUPA的原因之一，冯洪嘉敏那边不会给你模板抄，同时要求非常细致严格。
  5. 最终报告需要在Turnit上查重，CityU给3次免费查重机会，查重率不高于15%就行。与之相对的是，嘉敏那边不仅要求查重，还要求小组额外出具一份过程报告，详细列出参考过什么文献、使用过什么工具、每个组员每周都做了什么、报告中哪些部分是AI生成的、 使用AI时输入的prompt是什么等等，相当可怕。

展示：

  1. 一次中期展示和一次期末展示，展示全部都是线上ZOOM形式，唯一的要求就是全员开摄像头，不管你在地球哪个角落都好，能打开摄像头参会就行。
  2. 每次展示都是分成2周进行，中期展示是7-8周，期末展示是12-13周。然而其实整个班全部组也就十来个组，所以一次展示分成两周的话，每一周也就上5-6个组，这周不是你们组展示直接不用进会议，当这周没课就行；这周是你们组展示，你们组展示完之后就可以光速退出会议，非常省事。
  3. RUPA对每个组的展示的评价也是相当人机，基本都是_"Well done~"、"Excellent~"、"Good job~"、"Ok, next group~"_，不会给你任何压力。
  4. 展示对发言者数量没有要求，你可以一人全讲完，也可以每个人各说各的。

对RUPA的印象：

  1. 从上面其实已经可以看出，RUPA是个相当佛系的教授，特别是在隔壁有嘉敏这样的教授对比下尤为明显。13个教学周拿出整整4周来给大家做展示，1周就那么5-6组，不用一个半小时就能下班了，感觉RUPA比我们还懂摸鱼哈哈
  2. RUPA的讲课风格是比较经典的念PPT流，搭配印式英语确实很催眠。RUPA本人似乎也知道这一点，上着课经常走下来转一圈说“大家还醒着吗？”
  3. 虽然很佛，但是RUPA对学校的教学评价却又特别有执念。在期末的时候直接会在课上拉着要大家打开评教系统给她好评，哈哈，有点反差萌。
  4. 总之是很善良的一个老师。

考试：

  1. 开卷，不限纸张。忘了有没有选择题，只对简答题有印象了。总的来说不难，复习的时候把课件资料整理一下，考试的时候狂抄就好。给分也很友好。
  2. 相对应的，嘉敏那边的考试只允许带1张纸，并且只允许手写。所以嘉敏section的同学直到考前都很痛苦，都在A4纸上核舟记。不过嘉敏那边的试题难度是和RUPA一样的。

本门课我意外的是A+，完全超出我的预料，因为我真的对RUPA上课教的东西云里雾里的，没想到成绩还最好。

最后还是声明一点，本评论无意比较RUPA和嘉敏之间的“优劣”！嘉敏也是人特别好的老师，私下里经常关心学生，以上关于两个教授的对比只是想提醒大家，嘉敏的课堂要求会比RUPA严格很多，但这也仅仅只是两位教授在教学风格上的差异而已，并不是要评判孰优孰劣。

总而言之，如果你希望轻松过掉这门课（毕竟也是必修），推荐选RUPA；想要有点挑战性可以选嘉敏那边。

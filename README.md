# BIS Navigator

由 CityU MSc Business Information Systems 在读生与校友共同维护的中文学生手册，内容涵盖专业方向、课程选择、校内系统、实习发展与历届经验。

> 本项目为民间维护，不代表 City University of Hong Kong 官方立场。高时效信息请始终以学校、学院、学系及课程教师发布的内容为准。

## 本地开发

```bash
pnpm install
pnpm docs:dev
```

构建静态站点：

```bash
pnpm docs:build
```
